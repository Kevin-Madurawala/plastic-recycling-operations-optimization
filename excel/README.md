# Excel Analysis Workbook

This folder contains the Excel workbook used for the project.

[Download the workbook](Plastic%20Recycling.xlsx)

The workbook includes:
- Synthetic operational datasets
- PivotTable analysis
- KPI calculations
- Downtime analysis
- Pareto analysis
- Supporting calculations used before building the SQL and Power BI components

The dataset is synthetic and does not contain confidential company information.
